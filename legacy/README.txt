Пульт тестирования LLM и нечёткой оценки качества

1. В LM Studio включите сервер: вкладка Developer -> Start Server (порт 1234).
2. В Терминале:  bash ~/путь/к/llm_bench/start.command
   При первом запуске создаётся окружение .venv и ставятся зависимости.
   Откроется браузер с приложением. Остановка приложения — Ctrl+C в Терминале.
3. Боковая панель -> «Подготовить наборы» (один раз; скачиваются MMLU-ru и RuBia).
4. Вкладка «Прогон»: отметьте модели, режим «Пробный» (N=5), «Запустить».
   Убедившись, что всё работает, — режим «Полный».
5. Вкладка «Результаты и оценка»: показатели, оценки ВСММ / центроид / сумма / TOPSIS,
   выбор k и границ нормирования, объяснение по правилам, выгрузка CSV.

data/ — наборы, results/raw_metrics.csv — показатели, results/run.log — журнал.
Остановка прогона прерывает текущую модель (её результат не сохраняется);
уже измеренные модели при следующем запуске пропускаются.
Без интерфейса: python run_bench.py --prepare; python run_bench.py; python evaluate.py
